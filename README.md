# TRACE

> **Follow the evidence. Escape the pursuit.**

TRACE is a 2D maze game inspired by forensic investigation and pursuit scenarios.

The player explores a maze, collects evidence and tries to escape an autonomous police unit.

The project combines my background in **linguistics** with my new skills in **software development**, with the long-term goal of exploring NLP, speech technology and forensic applications.

## Getting Started

Clone the repository:

```bash
git clone <YOUR_REPOSITORY_URL>
cd trace
npm install
```

Start the development server:

```bash
npm run dev
```

Then open the URL shown in the terminal.
